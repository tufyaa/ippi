Задача 15.
Вам требуется провести исследование робастных методов оценивания параметров линейных и нелинейных (допустим, 2 порядка) моделей на данных, искажённых помимо аддитивного также и выбросовым шумом. Размерность пространства — 2. Задача состоит из двух частей: прямой и обратной. Прямая задача заключается в синтезе зашумлённого двумерного облака точек, а обратная — в устойчивом оценивании параметров модели, по которой был синтезирована выборка полезных (не выбросовых) данных. Представьте результаты экспериментального сравнения выбранных вами методов оценивания, зависимости качества от степени зашумлённости данных выбросами и от параметров алгоритмов оценивания. В качестве моделей распределения выбросового шума помимо равномерного рассмотрите структурированные шумы на ваше усмотрение.
