# Универсальный метод генерации синтетических данных с выбросами

## 1. Линейные данные

### Основная модель

Генерируется линейная зависимость с Гауссовским шумом:

$$
y = ax + b + \epsilon,\ \text{где}
\begin{cases}
a \sim \mathcal{U}(0.5, 3.0) \\
b \sim \mathcal{U}(-5.0, 10.0) \\
\epsilon \sim \mathcal{N}(0, \sigma^2),\ \sigma \sim \mathcal{U}(7, 25)
\end{cases}
$$

**Параметры:**

- Объем выборки: $N = 1000$
- Диапазон $x$: $[15, 85]$

## 2. Конические сечения

### 2.1 Эллипс

Параметрическое уравнение:

$$
\begin{cases}
x = c_x + a\cos t \cos\theta - b\sin t \sin\theta \\
y = c_y + a\cos t \sin\theta + b\sin t \cos\theta
\end{cases}
$$

где:

- $c_x, c_y \sim \mathcal{U}(30, 70)$
- $a, b \sim \mathcal{U}(10, 30)$
- $\theta \sim \mathcal{U}(0, \pi)$

### 2.2 Парабола

Каноническое уравнение:

$$
y = A(x-h)^2 + k,\ \text{где}
\begin{cases}
h \sim \mathcal{U}(30, 70) \\
k \sim \mathcal{U}(0, 100) \\
A \sim \mathcal{U}(-0.1, 0.1)
\end{cases}
$$

### 2.3 Гипербола

Параметрическое уравнение:

$$
\begin{cases}
x = h + a\cosh t \\
y = k + b\sinh t
\end{cases}
$$

где:

- $h, k \sim \mathcal{U}(30, 70)$
- $a, b \sim \mathcal{U}(10, 20)$

## 3. Механизмы генерации выбросов

### 3.1 Общие параметры

- Коэффициент загрязнения: $k \in \{0, 1, ..., 13\}$
- Объем выбросов: $N_{out} = \left\lfloor \frac{50k}{1-0.05k} \right\rfloor$

### 3.2 Типы выбросов

| Тип            | Формула                                                                                                | Параметры                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| **Кластерные** | $\begin{cases} x \sim \mathcal{N}(\mu_x, \sigma^2) \\ y \sim \mathcal{N}(\mu_y, \sigma^2) \end{cases}$ | $\mu_y = y_{true} \pm \Delta$, $\Delta \sim \mathcal{U}(20,50)$ |
| **Линейные**   | $y = a_{out}x + b_{out} + \epsilon$                                                                    | $a_{out} \sim \mathcal{U}(-3,3)$, $\sigma=2.0$                  |
| **Случайные**  | $\begin{cases} x \sim \mathcal{U}(0,100) \\ y \sim \mathcal{U}(y_{min}-25, y_{max}+25) \end{cases}$    | -                                                               |
